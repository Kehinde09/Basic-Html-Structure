# Single Page CV – Odukoya Kehinde  

This project is a clean and structured Single Page CV built using semantic HTML.  
It was created as part of the roadmap.sh Frontend Developer projects.

## 🔗 Project URL
https://roadmap.sh/projects/single-page-cv

## 📌 About the Project

This CV webpage presents:

- Personal and contact information
- Technical skills
- Educational background
- Professional experience
- Achievements
- Social links (LinkedIn & GitHub)

## 🎯 Purpose
The goal was to build a well-structured, semantic HTML document without using CSS or JavaScript.

## 🛠️ Built With

- HTML5
- Semantic HTML elements (`header`, `main`, `section`, `footer`)

## 📂 Project Structure

├── index.html
└── README.md


## 🚀 How to View

1. Clone or download this repository.
2. Open `index.html` in your browser.

## 🎯 Learning Objectives

This project focuses on:

- Writing clean HTML structure
- Using semantic elements correctly
- Organizing content logically
- Creating a professional CV layout
